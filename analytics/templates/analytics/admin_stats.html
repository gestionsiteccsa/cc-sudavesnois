Suppression d'une adresse IP (RGPD)

Pour supprimer toutes les données associées à une adresse IP, utilisez cette commande sur le serveur (SSH) : 

python manage.py supprimer_ip 192.168.1.42

Remplacer 192.168.1.42 par l'IP à supprimer. Les données sont conservées 1 an maximum.

Les adresses IP sont collectées à des fins de statistiques d'audience (intérêt légitime). Données conservées 1 an maximum. Consultez notre politique de confidentialité pour plus d'informations.
